# WordPress MCP Server

> **Development in progress — not ready for public deployment.**

Standalone, self-hosted Model Context Protocol server for connecting ChatGPT-compatible MCP clients to WordPress through the WordPress MCP Agent plugin.

Scope: WordPress content, media, Elementor, theme/plugin editing, backups, diagnostics, and site management. Unrelated marketing and social integrations are intentionally excluded.

Authentication and hosting documentation will be completed before a production release. Never expose unauthenticated write tools to the internet.
